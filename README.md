# GradeBook Analyzer
Gradebook Analyzer Project Overview The Gradebook Analyzer is a Python-based command-line tool designed to help teachers and administrators efficiently process student marks.
It allows users to input data manually or via CSV, automatically calculates statistical metrics (Average, Median, Min, Max),
assigns letter grades, and categorizes students based on Pass/Fail criteria.
Command-line tool for student grade analysis from manual input or CSV files.

## Features
- Manual entry & CSV import
- Statistics (avg, median, max/min)
- A-F grades (90+, 80-89, 70-79, 60-69, <60)
- Pass/Fail (>=40/<40)
- Grade distribution & formatted table
